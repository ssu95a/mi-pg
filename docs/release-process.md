\# Release Process



Процесс формирования релиза будет описан после стабилизации CI / delivery-процесса.



Основные темы:



\- формирование `release/\*`;

\- фиксация состава релиза;

\- сборка Update;

\- проверка зависимостей;

\- Windows-1251;

\- version comment;

\- SVN stamping;

\- тестирование поставки;

\- Git tag;

\- автоматизация CI/Python.



До формирования первого полноценного release основным процессом разработки является `workflow.md`.
